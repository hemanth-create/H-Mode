# Historical upstream results

These JSON results and dated reports were produced by the original upstream
project, not by Hemanth or an H-Mode benchmark run. They are retained unchanged
from the snapshot identified in the repository NOTICE.md.

The `rdxmin` arm is a historical upstream identifier. Keep it unchanged when
reproducing these datasets. New H-Mode live runs default to `h-mode-live/` and
must not be mixed into the historical suites or used to overwrite these files.

Charts generated from this data are labeled as upstream evidence. No quality,
cost, or token-savings claim for H-Mode follows solely from these results.
